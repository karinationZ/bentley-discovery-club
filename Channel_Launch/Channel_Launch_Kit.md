# Bentley's Discovery Club — Channel Launch Kit

> Build + brand + configure the channel **now** (in parallel with production). **Publish only when 5–6 episodes + 20–30 Shorts are banked.** Setup is ~30 minutes of clicks in YouTube Studio using the values below.

## 1. Channel name & @handle
- **Channel name:** **Bentley's Discovery Club** (keep it identical to the IP — it's your merch/brand name too).
- **@handle** — pick the first available (≤30 chars): `@BentleysDiscoveryClub` → `@BentleyDiscoveryClub` → `@DiscoverWithBentley` → `@BentleysClub` → `@BentleyExplores`.
- Set it once and keep it stable (it's your URL: youtube.com/@handle).

## 2. Brand identity
- **Motto / tagline:** **"Stop. Look. Listen. Discover!"** (also Bentley's in-show method).
- **One-line promise:** *"Join Bentley the curious Boxer on real nature adventures — a new animal, a new mystery, a new discovery every time."*
- **Palette (hex):** Teal `#17B0A7` · Coral `#FF7A59` · Sunny Gold `#FFC24B` · Sky `#8FD6E1` · Cream `#FFF6E9` · Navy text `#173A5E`.
- **Fonts (free, Google Fonts, kid-friendly):** Titles = **Fredoka** or **Baloo 2**; body = **Quicksand** or **Nunito**.
- **Avatar:** Bentley face badge (generated → `assets/branding/`).
- **Banner:** golden-hour tide-pool hero (generated) with the **title overlaid in post** (display font) — AI text is unreliable, so add the logotype yourself in Canva/CapCut.
- **Watermark:** a small glowing-shell or paw icon (bottom-right).

## 3. Channel settings — exact values (YouTube Studio)
- 🔴 **CRITICAL — Audience:** Settings → Channel → Advanced settings → "Set your channel as made for kids?" → **"Yes, set this channel as made for kids."** (Legal, COPPA.)
- **Default uploads:** Made for Kids = **Yes**; Category = **Education** (A/B vs Entertainment); Language = English; License = Standard; add captions.
- **Channel keywords:** `bentley, kids educational, animals for kids, nature for kids, tide pool, ocean animals, learning cartoon, preschool, science for kids, animated educational, STEM kids`.
- **Country:** your location. **Business email** + **links** (website/store when ready).
- **Branding:** upload watermark; set channel trailer (the cold-open teaser) + a featured video for the Home tab.
- ⚠️ Note the MFK constraints: comments off, no community posts, no personalized ads, end-screens/cards disabled. Plan growth around Shorts + thumbnails + playlists.

## 4. Video metadata templates
**Title formula:** `[BENTLEY + ACTION VERB IN CAPS] + [curiosity gap] + emoji | Bentley's Discovery Club`
- e.g. "Bentley Hears a VOICE in a Shell?! 🐚 | Bentley's Discovery Club Ep 1"

**Description template:**
```
Bentley hears a tiny voice in a shell… and discovers a whole secret world in the tide pool! 🐚
Join Bentley the curious Boxer as she learns to Stop, Look, and Listen.

🌊 This adventure: [one line]
🔎 Discovery Notes (for grown-ups):
 • [Fact 1]
 • [Fact 2]
 • [Fact 3]
🐾 Try this at home: [simple prompt]

▶ Next adventure: [link]
▶ All episodes: [playlist link]

Bentley's Discovery Club — where every question is an adventure. New episodes weekly!
#BentleysDiscoveryClub #KidsEducational #ForKids #Animals #LearningForKids
```

**Thumbnail spec:** 1280×720; Bentley's expressive face ≥40% of frame; ONE curiosity object; bold color-coded background (teal=ocean, gold=desert, green=forest); big simple shapes readable at 120px; same logo bug + font every time.

## 5. Playlist architecture (boosts SEO + autoplay/session time)
- **Bentley's Discovery Club — Full Episodes** (ordered, pilot first) → set as **featured** for binge/autoplay.
- **Bentley Shorts**
- **Under the Sea 🌊** (tide pool, octopus, shark, whale, ocean rescue)
- **Tiny Worlds 🔬** (ants, bees, shrink episodes)
- **On the Move 🦋** (butterflies/migrations, talking trees)
- **Did You Know? — Animal Facts** (fact Shorts)

## 6. SEO / discovery
- Target phrases: `"[animal] facts for kids"`, `"tide pool for kids"`, `"ocean animals cartoon"`, `"educational cartoon for kids"`, `"learn about [animal]"`.
- Put the primary keyword in the **title + first line of the description + a tag**.
- Consistent thumbnail grammar = instant brand recognition in the sidebar.
- Cross-post Shorts to **TikTok + Instagram Reels** for extra discovery, funneling back.

## 7. Launch-day checklist
- [ ] Channel set **Made for Kids**.
- [ ] Avatar + banner uploaded; About + links + keywords set.
- [ ] Playlists created; Full Episodes featured.
- [ ] 5–6 episodes + 20–30 Shorts banked.
- [ ] Publish **Pilot + Ep 1 together**; schedule the rest weekly (same day/time).
- [ ] Start **daily Shorts**; cross-post to TikTok/Reels.
- [ ] Distribute theme + fact songs to YouTube Music/Spotify.
