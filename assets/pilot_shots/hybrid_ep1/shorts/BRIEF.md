## The six launch tests (one Short each — must be DISTINCT, not near-identical)
1. **Character appeal** — make cold viewers like & understand Bentley
2. **Mystery** — an immediate unanswered question
3. **Science surprise** — a surprising hermit-crab fact
4. **Comedy** — Bentley's funniest clear mistake/reaction
5. **Emotional connection** — make viewers care about Pip & Bentley
6. **Adventure / cliffhanger** — curiosity about the full episode

## Hard rules for every Short
- Hook in the first **1–2 s**; first frame = a **face / problem / surprise / clear mystery** (no slow establishing shots).
- **One** central idea. Must work **standalone** for someone who's never seen Episode 1.
- Introduce enough context for a first-timer; **never** say "Bentley is back" / "as you already know."
- **Large readable captions** in the safe area (not under the bottom-right Shorts UI).
- Accurate science. No frightening / overly-angry / excessive reactions. No unlicensed music. Don't ask kids to comment or leave YouTube.
- End on **discovery / surprise / curiosity / a loop / a reason to watch Episode 1.**
